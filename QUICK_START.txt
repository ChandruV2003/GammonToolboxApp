◐ TO RUN THE APP:

1. Open Terminal and navigate to the project:
   
   cd /Users/admin/Developer/GammonToolboxApp

2. Start the development server:
   
   npm start

3. Choose how to view:
   
   • Press 'w' → Opens in web browser (EASIEST!)
   • Press 'i' → Opens iOS Simulator (needs Xcode)
   • Press 'a' → Opens Android Emulator (needs Android Studio)
   • Scan QR code → Use Expo Go app on your phone

◈ WHAT'S INCLUDED:

● API Gravity Correction Calculator
   → Input: API Gravity, Temperature, Fuel Type
   → Output: Corrected API Gravity
   → Fuel Types: Gasoline, Diesel, Jet A/Kerosene
   → Temp Units: Fahrenheit & Celsius

● Weight from Volume Calculator
   → Input: Volume (Gallons or Litres)
   → Output: Weight (lbs or kgs)
   → Uses calculated density from API correction

● Contact Information
   → Links to website and email
   → Company details
